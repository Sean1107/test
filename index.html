01 化學反應速率的定義、化學計量數換算與速率方程

化學反應速率用來衡量反應進行的快慢，通常以單位時間內反應物濃度的減少量或生成物濃度的增加量表示（取正值）：

v = Δc / Δt = Δn / (V · Δt)  （常用單位：mol·L−1·s−1 或 mol·L−1·min−1）

對於通式反應 aA(g) + bB(g) ⇌ cC(g) + dD(g)，同一時間段內各物質表示的平均速率之比等於化學計量數（係數）之比：

v(A) : v(B) : v(C) : v(D) = a : b : c : d  ⇒  v歸一化 = v(A)/a = v(B)/b = v(C)/c = v(D)/d
  • 比較不同條件下的反應快慢：必須遵循「一統單位（全部換成 mol·L−1·s−1，注意 1 mol·L−1·s−1 = 60 mol·L−1·min−1）、二除係數（計算 v(X)/係數）」，歸一化數值愈大代表反應愈快。
  • 速率定律（Rate Law）與反應級數：在一定溫度下，瞬時速率 v = k[A]m[B]n。指數 m, n 為反應級數，必須由實驗數據（初始速率法）測定，不一定等於化學計量數 a, b。
  • 速率常數 k 的性質與單位：k 只受溫度與催化劑影響，與反應物濃度無關。總級數為 N = m + n 的反應，k 的單位為 mol1−N·LN−1·s−1（例如二級反應為 L·mol−1·s−1）。

02 互動式活化能與化學平衡動態曲線模擬

04 化學平衡常數 Kc / Kp、反應商 Qc 與勒沙特列原理

濃度平衡常數 Kc 與壓強平衡常數 Kp

Kc = ([C]c · [D]d) / ([A]a · [B]b)
Kp = (p(C)c · p(D)d) / (p(A)a · p(B)b)

• 純固體 (s) 與純液體 (l) 不寫入表達式（活性視為 1）。
• Kc 與 Kp 只受溫度影響，與起始濃度、壓強、催化劑無關。

反應商 Qc 判斷平衡移動方向
  • • Qc < Kc：v正 > v逆，反應向正反應方向（右）進行。
  • • Qc = Kc：v正 = v逆 > 0，體系處於化學平衡狀態。
  • • Qc > Kc：v正 < v逆，反應向逆反應方向（左）進行。
